# Flutter assets

- `logo.png` is the airplane mark created for Lab 2.
- `open_space.png`, `global_will.png` and `tallest_building.png` are local illustrations for the tutorial's three sample hotel records.
- `search_offer.png` is the original airplane illustration shown on the search page.

The Flutter asset manifest includes `assets/images/` so all four screens can display images without a network connection.

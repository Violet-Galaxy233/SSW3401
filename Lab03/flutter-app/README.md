# SSW3401 Lab 3 — Flutter Ticket Booking

This project continues Lab 2 with flight and hotel lists, search, and detail pages.

Run `flutter pub get` and `flutter run` from this folder with an Android emulator or device available. Use `flutter analyze` and `flutter test` to check source and widget behavior.

- `lib/main.dart` registers named routes.
- `lib/screens/` contains the home, search, ticket, and hotel layouts.
- `lib/widgets/` contains the shared headings, tabs, flight cards and hotel cards.
- `lib/data/catalog.dart` contains the tutorial's sample records.
- `assets/images/` contains the booking logo and local travel illustrations.

See the [Lab 3 overview](../README.md) for the tutorial coverage and demonstration.

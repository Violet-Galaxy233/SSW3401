# Local image asset

`images/logo.png` is an original airplane logo created for this lab. Its reproducible generator is `../tool/generate_logo.py`.

The tutorial links to https://www.dbestech.com/tutorials/flutter-ticket-booking-app for its original assets. That download returned HTTP 403 on 11 November 2026. This project substitutes a local airplane image while retaining the tutorial's AssetImage, DecorationImage, Container and rounded-corner loading method.
